# lal-support-suite plugin (v3.1.0)

Teaches Claude to run the LAL Support Suite: build a case file from matter documents, explain any number, run a mediation session with the ED boards, prepare the Form 12.902(c) financial affidavit, import affidavits and disclosure into the ED inventory, and use the goal planner.

```
lal-support-suite/
├── .claude-plugin/plugin.json
└── skills/lal-support-suite/
    ├── SKILL.md
    ├── references/case-file-schema.md
    ├── references/calculation-basis.md
    ├── references/ed-chart-format.md
    ├── references/fa-12902c-line-map.md
    └── assets/lal-support-suite.artifact.html   (v3.1 app source as published)
```

Install by adding `lal-support-suite.plugin` (or this folder) in Claude. Release notes: `LAL Support Suite v3.1 - README.md` in the product folder and the CHILD SUPPORT CALCULATOR project.
